# Hiring Gauntlet

Scope: Application Journey only. Mode: Read, with interactive status inspection. Audience: portfolio visitors interpreting the current filtered job search. User approved direct SVG implementation.

## Direction contract

THESIS: A vintage recruitment board game whose checkpoints explain current status, never imply historical movement.

OWN-WORLD: Warm cream, navy outline illustrations, forest-green route, amber paperwork accents, muted-red rejection area. Retain the surrounding dashboard typography. Small consistent SVG objects, no raster assets.

STORY: Read the filtered total, inspect the eight current counts, read each visible tagline and cohort share. Rejection and Unknown remain separate. Global filters refresh the same cohort denominator.

FIRST VIEWPORT: Title and filtered total above a four-by-two serpentine board. Top row reads left to right; bottom row returns right to left. Numbered checkpoints have an illustration, professional label, count and share. A separate rejection strip follows. Mobile becomes a compact vertical list. Signature motion: hover lifts artwork; a short sequential route reveal stops at the furthest populated current stage and updates with global filters. No click behavior, tooltips or details. Entrance is one short board reveal, with reduced motion disabled.

FORM: User-pinned board-game route; precisely scoped component replacement, no concept seed needed. Direct SVG build explicitly approved.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
