# V1 verification — 2026-10-15

## Automated checks

- Bun 1.4.2: `bun install --frozen-lockfile` succeeded.
- `bun run check`: **51 tests passed across six files**, strict TypeScript passed, Worker/client production builds passed.
- `git diff --check`: passed.
- Client source/build inspection found no Worker imports, private fixture notes, or Google credential/configuration identifiers.
- API tests inject sensitive sentinel strings and assert that no raw private fields or values escape the aggregate response.

## Browser verification

Headless Chromium tested both Vite development mode and the production-built Worker under Wrangler preview. Local browser automation was used because no in-app browser connection was available.

- Five Plotly charts and the native current-state distribution render.
- No page-level horizontal overflow at 1440px desktop or 390px mobile.
- Country selection, date basis, date bounds, activity interval/cumulative controls, demo search and empty results work.
- API 404/405 behavior, source error display and retry work.
- Clicking an actual world-map marker updates the country filter.
- When local map topology is blocked, the error message appears and the ranked country table still filters the dashboard.
- API navigation requests with an HTML Accept header still return JSON 404 for unknown API routes.
- `/.dev.vars` does not serve local configuration.
- No unexpected browser errors in the completed interaction suite.

## Independent reviews

Code review found an inherited `lib/` ignore rule that would omit frontend helpers and a filter-date whitespace normalization mismatch. Both were corrected. Cache concurrency, reuse, expiry and expired-source failure now have explicit tests.

The impeccable mechanical detector reported no findings. Independent visual review found inactive interval contrast and mobile KPI definition overflow. Corrected contrast is 5.10:1. A reproduced 413px popover edge in a 390px viewport moved to 367px after correction. The visual reviewer scored both findings resolved in its verdict pass; that pass did not constitute a new whole-application audit.

Local screenshots are in the ignored `.impeccable/review/` directory.

## Limits

Actual credentialed Google Sheets access and public deployment were not performed. The signed JWT/read-only scope/token/retrieval flow was tested with mocked Google responses. Service-account and Cloudflare setup remain manual. No formal screen-reader audit was performed. The lazy-loaded custom Plotly bundle is approximately 464 kB gzip and emits a non-failing Vite chunk-size warning.
