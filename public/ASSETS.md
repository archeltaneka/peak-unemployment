# Public assets

- `favicon.svg`: authored for Peak Unemployment; geometric brand mark.
- `world_110m.json`: Plotly's 110m world topology, downloaded from https://cdn.plot.ly/world_110m.json on 2026-10-15 and served locally to avoid runtime CDN requests. It contains country boundaries only, never application data.

The Manrope variable font is bundled from `@fontsource-variable/manrope`; its upstream font license is included in that installed package. Plotly and React package license information remains in their dependencies.
